# 郑大三附院生殖医学科文献汇报第168期预告+亚太生殖年会热点解读

> 更新时间：2026-09-17 (UTC+8)

****

**文献摘要：**
**研究背景：**生长激素(GH)对在体外受精（IVF）中的积极作用通常归因于其对于卵母细胞和胚胎质量的改善。虽然新出现的证据强调GH可以改善子宫内膜功能的，但这些结果目前仍存在争议。

**研究目的：**本meta分析旨在评估在IVF周期内给予生长激素是否能改善子宫内膜功能和生殖结局，从而指导临床实践。

**检索方法:**在Cochrane Central Register of Controlled Trials、PubMed 以及Embase中进行的文献检索一直持续到2021年11月30日,我们还手动检查已确定的研究、会议记录或临床试验注册网站的参考文献，以获取额外的潜在相关数据没有语言限制。纳入评估GH对IVF结果影响的随机对照试验(RCT)。偏倚风险和证据质量(QoE)根据Cochrane 协作网的工具和建议分级评估统进行评估。通过随机效应模型进行荟萃分析，二分类变量资料用优势比 （OR）表示和连续型变量资料用均数差（MD）表示，并计算其95%置信区间(CI)。I2 统计量用于评估异质性对荟萃分析的影响。I2 ＜40% 认为没有异质性， 30%- 60%为中等异质性，50 %-90%为重大异质性，75%-100%为重度异质性。采用meta回归和亚组分析来解释研究之间异质性的潜在来源。

**结果:**** **共纳入25项试验2424名女性。17项关于卵巢低反应（POR）的RCT (n = 1723)显示，GH可显著增加子宫内膜厚度(EMT) (MD = 0.38, 95% Cl: 0.18-0.59;中度QoE)，这有助于提高活产率(OR = 1.67, 95% Cl: 1.13-2.49;QoE极低)和临床妊娠率(CPR) (OR = 1.97, 95% Cl: 1.43-2.72;低QoE)。亚组分析显示GH应用与IVF结果之间存在剂量和时间依赖关系;改善CPR的最佳建议与EMT一致，而不是卵母细胞和胚胎的质量。因此，GH可能通过影响子宫内膜来提高生育能力。从上一个周期的卵泡期开始每天应用GH（< 5IU /天）到HCG日，可显著提高子宫内膜厚度，怀孕的机会更大，而GH5IU-10IU /天或从上一个周期的黄体期开始到HCG注射日，可以提高卵母细胞和胚胎质量。相比其他刺激方案联合GH，POR患者可能受益于GnRH激动剂长方案联合GH治疗。对关于GH在薄型子宫内膜的应用一共有4项RCT(n = 354)，研究结果显示在生长激素治疗期间，子宫内膜功能的改善可能是改善生殖结局的关键因素，因为没有发现胚胎质量的改善。GH不仅增加了EMT (MD = 1.48, 95% Cl: 1.21-1.75;中度QoE)也可促进子宫内膜形态(OR = 2.67, 95% Cl: 1.36-5.23;低QoE)和子宫内膜血流灌注(OR = 5.84, 95% Cl: 1.30-26.17;低QoE)，从而改善CPR (OR = 2.71, 95% Cl: 1.69-4.34;l P < 0.000;体验质量低)。没有足够的证据得出GH对正常反应者的影响的结论(n = 80)。由于CPR的明显改善，子宫内膜较薄的女性可能是GH最合适受益人群。

**更广泛的意义: **改善子宫内膜功能可能是生长激素改善体外受精结局的另一个重要机制。应根据目标人群的个人情况和需要，向他们提供最佳治疗。由于样本量有限和方法问题，QoE的证据级别是中等到非常低的;因此，对结果的解释应谨慎。需要更严格的大样本量的随机对照试验来确认效果并确定最佳的GH应用方案。
